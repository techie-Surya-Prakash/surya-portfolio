SPIDER-VERSE PORTFOLIO — SURYA

FILES
- index.html       Main website structure
- style.css        Design, Spider-Man-inspired red/blue theme, responsive layout
- script.js        Mobile menu and active navigation
- assets/surya.jpg Your supplied portrait, already connected to the page

HOW TO PREVIEW
1. Extract the ZIP.
2. Open index.html in a browser, or open the folder in VS Code and use Live Server.
3. Keep the assets folder beside index.html. Do not move surya.jpg out of assets.

HOW TO PUBLISH ON GITHUB PAGES
1. Upload index.html, style.css, script.js, and the assets folder into the root of your repository.
2. Commit the files.
3. In GitHub, open Settings > Pages and select your deployment source/branch if it is not already configured.
4. Open your GitHub Pages URL after deployment finishes.

CUSTOMIZE
- In index.html, replace your-email@example.com with your email.
- Update the About, Skills, and Projects text to match your real experience.
- The Gaming Hub and Code Lab project cards are concept placeholders, not links to finished projects.
